<h1 align="center">綴り Tsuzuri</h1>
<p align="center"><i>Read, fill, sign and edit PDFs. Part of 工房 Kōbō.</i></p>

Tsuzuri is CuteClaudia's PDF app, for **Windows** and **Linux**, and in the browser on
[claudiagilbert.com](https://www.claudiagilbert.com). Download the latest version from
**[Releases](https://github.com/cuteclaudia/tsuzuri-releases/releases/latest)**.

| Platform | Download | How to install |
|---|---|---|
| Windows 10 / 11 (64-bit) | `tsuzuri-<version>-windows-x64-setup.exe` | Run it. If Windows shows "Windows protected your PC", choose **More info → Run anyway** (or right-click the file → Properties → **Unblock**). |
| Windows, no install | `tsuzuri-<version>-windows-x64-portable.zip` | Unzip and run `tsuzuri.exe`. |
| Linux (any distro) | `tsuzuri-<version>-linux-x86_64.AppImage` | Make it executable, then run it. |
| Ubuntu, Debian, Mint | `tsuzuri-<version>-linux-x86_64.deb` | Open it with your software centre, or `sudo apt install ./tsuzuri-*.deb`. |
| Fedora, openSUSE | `tsuzuri-<version>-linux-x86_64.rpm` | `sudo dnf install ./tsuzuri-*.rpm` |

Each release lists `SHA256SUMS.txt` to check your download. Every release passes a security
check first: known vulnerabilities, where its code comes from, everything it can connect to, and
a virus scan of the files. Installed copies offer new versions when they're published here.

Tsuzuri is based on [PdfCraft](https://github.com/storytold/pdfcraft) by the ArtCraft Team and
the PdfCraft contributors, and is licensed MIT OR Apache-2.0.
